# README

## Лабораторная работа №1

**Цель работы:** Изучение правил разработки классов.  

---

## Описание проекта

Данный проект представляет собой консольное приложение на языке C# (платформа .NET), реализующее три независимых задания в рамках лабораторной работы по объектно-ориентированному программированию. Основной акцент сделан на разработке классов, инкапсуляции, работе с конструкторами и методами.

Проект состоит из двух частей:
- **Часть 1** — работа с данными об автомобилях (ввод, хранение, удаление).
- **Часть 2** — три задания на разработку классов с различной функциональностью.

---

## Функциональность

### Часть 1. Учёт автомобилей

Программа позволяет пользователю в интерактивном режиме:
1. **Добавить сведения о машине** — вводятся:
   - Государственный регистрационный номер (проверяется на соответствие формату: буква, три цифры, две буквы).
   - Модель (непустая строка).
   - Цвет (непустая строка).
   - ФИО владельца (непустая строка, без цифр).
2. **Удалить сведения о машине** — по введённому регистрационному номеру.
3. **Завершить сеанс** — выход из программы.

Все данные хранятся в оперативной памяти в списке `List<Car>`.

### Часть 2. Задания на классы

#### Задание 2.1. Класс `Character`
- Приватное символьное поле `cr`.
- Три открытых метода:
  - `SetChar(char cha)` — присваивает значение полю.
  - `CharCode(char cha)` — возвращает код символа.
  - `PrintChar()` — выводит символ и его код в консоль.
- Пользователь вводит один символ, после чего программа выводит его и код.

#### Задание 2.2. Класс `TwoSimbols`
- Два символьных поля: `One` и `Two`.
- Метод `Method()` без аргументов и возвращаемого значения.
- Выводит все символы из кодовой таблицы, находящиеся «между» значениями полей (включительно). Если первый символ меньше второго — вывод в прямом порядке, иначе — в обратном.

#### Задание 2.3. Класс `IntFields`
- Два целочисленных поля: `NumOne`, `NumTwo`.
- Три конструктора:
  - Без аргументов.
  - С одним аргументом (инициализирует `NumOne`).
  - С двумя аргументами (инициализирует оба поля).
- Демонстрируется создание объекта с двумя аргументами и вывод значений.

## Вспомогательные методы

- `NormalizeInput(string prompt, string errorMessage)` — запрашивает ввод до тех пор, пока не будет введена непустая строка.
- `IsThisTrueRegNumber(string input)` — проверяет формат регистрационного номера (буква, 3 цифры, 2 буквы).
- `GetRegNumber()` — комбинирует ввод и проверку регистрационного номера.

## Примечания

- Все данные хранятся только в памяти и не сохраняются между запусками.
- Ввод пользователя валидируется: пустые строки, цифры в ФИО, неверный формат номера — обрабатываются с повторным запросом.
- Классы `Car`, `Character`, `TwoSimbols`, `IntFields` объявлены как вложенные в `Program` (кроме `Car`), что соответствует заданию.
